# Будущие видеоматериалы

Видео пока нет. Размещать только материалы с подтвержденным правом публичного распространения и необходимыми согласиями изображенных людей. Согласия и персональные документы в репозиторий не загружать.

Имя видео должно соответствовать video_path в словаре. Перед включением в демо проверить значение жеста, язык/вариант, читаемость рук и лица, работоспособность воспроизведения. Заглушки не обозначать как проверенные жесты.
