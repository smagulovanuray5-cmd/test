Данных пока нет. Подготовка — Issue #2.

Для каждой записи нужны: id, term, text_language, sign_language, definition, video_path, source, rights, review_status. Для вариантов добавить variant; для поиска допустим список aliases. Факт проверки фиксировать через reviewed_at и неперсональный идентификатор роли проверяющего.

review_status: draft / approved / rejected. В выдачу допускается только approved при подтвержденных правах. Проверку проводят специалист по выбранному жестовому языку и представитель целевой аудитории.

Язык текста не определяет автоматически жестовый язык. Не добавлять вымышленные видео, непроверенные соответствия или персональные данные. Документы согласий хранятся вне публичного репозитория; здесь допустим только неперсональный учет разрешений.
