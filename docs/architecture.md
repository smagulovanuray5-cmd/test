# Предложение архитектуры

Статус: проект решения. Технический стек не выбран, код отсутствует.

Для первого сценария достаточно статического веб-приложения: учебный текст и поиск в браузере, небольшой локальный JSON-словарь, разрешенные видеоматериалы. Сервер, база данных, авторизация и внешние ИИ API пока не нужны.

## Предлагаемые части

| Путь | Будущая ответственность |
| --- | --- |
| apps/web/ | Интерфейс, поиск, видеокарточка и обработка ошибок |
| data/ | Проверенные метаданные терминов |
| assets/signs/ | Разрешенные видео небольшого демонстрационного набора |
| docs/ | Решения, проверки и ограничения |

Не передавать введенный текст внешним сервисам, не сохранять его между сессиями. Видео загружать по действию пользователя; при недоступности показывать ошибку. Внешнее видеохранилище вводить только при необходимости и с документированным поведением загрузки.
